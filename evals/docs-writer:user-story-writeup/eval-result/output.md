## Import and categorize transactions from a CSV upload

A user has a CSV export of their transactions sitting on their computer,
already categorized by hand in the past. Right now there's no way to get
that data into the app at all. This slice lets them upload that CSV,
automatically match each transaction to a category based on their own
prior categorization, and see the result as a real list — no more manual
retyping.

**What this looks like once it ships:**
- The user uploads a CSV export of transactions.
- Each transaction is automatically assigned a category by matching it
  against the user's previously-categorized sample data.
- The user sees the imported, categorized transactions in a list.

**What this doesn't cover yet:** live bank connections, budget-vs-actual
comparison, or moving money between accounts — those are later pieces of
work, not part of this one.
