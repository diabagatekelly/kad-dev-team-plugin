# Scope Map: Personal Accounting Automation (scope-map-001)

## Status
Active

## Steps
1. Transaction ingestion — pull transaction data from the user's financial
   accounts automatically, replacing manually logging into each account.
2. Categorization — assign each transaction to a budget category,
   replacing manual categorization.
3. Budget & spending view — show spending against budgeted amounts per
   category, replacing the manual check against budget.
4. Money movement — determine and surface what money should move between
   accounts (e.g. checking to savings), replacing the manual end-of-month
   transfer decision.
