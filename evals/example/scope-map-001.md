# Scope Map: Manual Excel-Based Personal Accounting (scope-map-001)

## Status
Active

## Steps
1. Account & transaction sync — connect to the user's financial accounts and
   retrieve transaction data automatically, replacing manual login-and-copy.
2. Transaction categorization — categorize retrieved transactions, informed
   by the user's sample of historically-categorized transactions.
3. Budget tracking view — show spending against each category's budget,
   based on categorized transactions, replacing the manual Excel check.
4. Checking-to-savings transfer guidance — surface a transfer amount based
   on the budget-vs-actual picture at period end.
