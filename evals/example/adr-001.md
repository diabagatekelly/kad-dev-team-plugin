# ADR-001: Use Plaid for bank account connection and transaction retrieval

## Status
Accepted

## Context
The project needs to connect to the user's bank and retrieve transactions
automatically, replacing the manual login-and-copy process described in
problem.md. The problem doc's security constraint requires this connection
to be built and operated securely; only the AI-assisted categorization
capability carries a hard "must stay free" constraint — the bank-connection
piece itself wasn't given that same hard requirement. A custom scraper
against bank login pages was ruled out early, since it would require
storing the user's raw bank credentials ourselves, directly conflicting
with the security constraint, and would break on every bank UI change. That
leaves a third-party bank-aggregation vendor, isolated behind a single
adapter, as the realistic path.

## Decision
Use Plaid as the bank-aggregation vendor for connecting to and retrieving
transactions from the user's account.

## Alternatives considered
- **SimpleFIN** — built specifically for personal-finance hobby projects,
  with a free tier aimed at single-user personal use and a simpler API.
  Rejected in favor of Plaid: smaller vendor, narrower institution
  coverage, and a less established security track record for a system
  that explicitly must be "very secure."
- **Custom scraper against bank websites** — rejected outright: requires
  storing the user's raw bank login credentials ourselves, conflicting
  directly with the security constraint, and is fragile against every
  change to the bank's own site.

## Consequences
- Easier: broad institution coverage and a well-documented, widely-trusted
  integration path for a system where security matters most; less custom
  credential-handling code to build and audit.
- Harder: Plaid's free/developer-tier terms have shifted over time and need
  verifying against current pricing before being relied on long-term; if
  those terms change unfavorably, this becomes costly to unwind since the
  connection adapter and onboarding flow are built around Plaid's specific
  API shape.
- Forecloses: building toward SimpleFIN's simpler, hobby-project-oriented
  model unless a future ADR supersedes this one.
