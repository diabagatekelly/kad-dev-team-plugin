# ADR-002: Send due-date reminders by email only

## Status
Accepted

## Context
Members asked for a reminder before a loan falls due. Email is free, and
almost every member has given an address.

## Decision
Due-date reminders go by email only. We will not send reminders by SMS or
post.

## Alternatives considered
- SMS: per-message cost, and a second provider to maintain.
- Post: printing and postage for every reminder.

## Consequences
Members without an email address get no reminder.
